# Apothika — Inventory & Business Management System

Apothika is a React + TypeScript business management application focused on inventory, stock movement, purchasing, and operational workflows.

## Included

- Responsive landing page
- Authentication and protected dashboard
- Business dashboard
- Product management
- SKU and barcode support
- Inventory search and filtering
- Stock In / Stock Out
- Stock adjustments
- Supplier management
- Purchase management
- Inventory transaction history
- Inventory reports and analytics
- Batch and expiry foundations
- Barcode scanning
- Barcode label generation
- Supabase integration
- Workspace/business separation

## Technology

- React 19
- TypeScript
- Vite
- Supabase
- React Router
- Tailwind CSS
- Recharts
- Lucide React

## Setup

Install dependencies:

    npm install

Create your environment file:

    cp .env.example .env

Add your Supabase credentials to .env.

Start development:

    npm run dev

Create a production build:

    npm run build
