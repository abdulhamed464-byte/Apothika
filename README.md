# Apothika

**Production-ready inventory and business management SaaS for growing businesses.**

🌐 **Live Demo:** https://apothika.vercel.app

## Overview

Apothika is a modern inventory and business management SaaS application designed for small and growing businesses.

It provides a foundation for managing products, inventory, purchasing, suppliers, stock movements, and business operations through a responsive web dashboard.

The application is currently deployed and operational with authentication, protected dashboard functionality, and Supabase backend integration.

## Current Features

- User registration and authentication
- Protected business dashboard
- Product management
- SKU management
- Inventory management
- Stock In / Stock Out workflows
- Stock adjustments
- Purchase management
- Supplier management
- Inventory transaction tracking
- Dashboard analytics
- Responsive web interface
- Supabase authentication and backend
- Production deployment on Vercel
